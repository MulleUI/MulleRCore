# Demo Resources

The `main-rcore-bone-socket` demo requires these model files from the raylib
examples repository:

```
resources/models/gltf/greenman.glb
resources/models/gltf/greenman_hat.glb
resources/models/gltf/greenman_sword.glb
resources/models/gltf/greenman_shield.glb
```

Download from:
https://github.com/raysan5/raylib/tree/master/examples/models/resources/models/gltf

Or copy them from a local raylib checkout:
```bash
cp raylib/examples/models/resources/models/gltf/greenman*.glb resources/models/gltf/
```
